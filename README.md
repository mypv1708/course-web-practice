# 🌐 Web Development Learning Roadmap

📘 _A structured self-study journey to review core concepts of HTML, CSS, and JavaScript._

---

## 📂 Folder Structure

This repository is organized into 12 sections, progressing from basic to advanced topics in frontend development.

### 🔹 HTML

1. **HTML Fundamentals**
2. **HTML Elements and Their Attributes**
3. **HTML Forms**

### 🔹 CSS

4. **CSS Basics**
5. **CSS Spacing (Margin, Padding)**
6. **CSS Units (px, %, rem, etc.)**
7. **CSS Display Property & Values (block, inline, etc.)**
8. **CSS Grid Layout**
9. **CSS Intermediate (Selectors, Inheritance, etc.)**

### 🔹 JavaScript

10. **JavaScript for Beginners**
11. **JavaScript Intermediate**
12. **JavaScript Advanced Topics**

1. Browse each folder in order.

4. Optionally, add your own notes or improvements.
